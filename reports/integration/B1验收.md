## 运行与后续边界

按根 README 安装并启动后端；或执行下列命令让检查脚本自行启动、读取、关闭：

```powershell
.\.venv\Scripts\python.exe reports/integration/verify_b1_http.py --mode stub --port 8000
```

若端口已占用，使用 `--port 0`，脚本不会关闭其他服务。真实模式使用 `--mode real`，可能加载 A 的本地模型，但该脚本仍只检查 HTTP 健康状态。

B1 不包含聊天/会话 API、产品长期记忆、训练、真实模型效果、正式输入输出适配、GPU/禁网镜像验收或赛事提交。演示 stub 和本轮 JSON 样例不是可回退的参赛候选。正式禁网推理与候选保留仍须 B5–B7 实际验收。

本轮没有需要人工解决的技术阻塞；用户只需按既定分工合并、拉取 PR。下一阶段为 B2，等用户点名再开始。B0 未明确但不阻塞的细项继续留档，不重复追问。
