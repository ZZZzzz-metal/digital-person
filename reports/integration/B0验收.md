## 复核运行方法

使用 Python 3.12，在本项目根目录执行：

```text
python reports/integration/verify_b0_reference.py --report reports/integration/b0-local-probes.json
```

脚本校验原始摘要、读取样例，并在确认缺模型/缺激活脚本的前提下探测原流程失败路径。当前 Windows 的 shell 探测使用 Git Bash，不代表官方 Linux 环境。它不安装模型、不耗卡、不提交作品。

另外在已安装 jsonschema 的 Python 环境执行 `python reports/integration/verify_b0_effective_schema.py`，重现有效 schema、原样 ID 和结构负例检查。它只写核对报告，协议合成回复不落盘；报告明确 `protocol_fixture_only=true`、`model_inference_verified=false`。

完整事实、来源和后续分工见 [官方接口核对](../../docs/官方接口核对.md)。机器可读状态为 [b0-readiness.json](../../contracts/official/b0-readiness.json)，`b0_complete=true` 按用户接受非阻塞未知项的核心协议收尾定义记录；`model_inference_verified`、`official_container_verified`、`official_submission_ready` 仍为 `false`。
