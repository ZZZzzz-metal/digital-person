## 1. 先进入官方咨询入口

1. 用电脑打开[报名与作品提交页](https://ai.migudm.cn/interactive/match/registration)，需要时用你报名的账号登录。
2. 在页面找到并点击 **“联系客服”**。2026-10-10 实际查看，点击后弹出 **“扫描加企业微信咨询”** 二维码，注明客服每天 **9:00–22:00 在线**。
3. 用手机微信扫一扫二维码，按微信提示添加该客服。在微信里发送下方整段咨询文字，说明你参加的是 **B2 数字人综合情感陪伴对话模型**。
4. 如果客服不能解答技术问题，请其转技术支持。备用入口是[技术赛道细则](https://ai.migudm.cn/interactive/rules/AI%E6%8A%80%E6%9C%AF%E8%B5%9B%E9%81%93%E5%8F%82%E8%B5%9B%E7%BB%86%E5%88%99.html)，滚到页面最底部“七、联系我们”，用微信扫 **“AI技术赛道官方咨询群”** 的二维码，按提示加入并询问。

## 2. 复制给官方的文字

5. 平台一键上传以及外部镜像上传的最新版操作手册在哪里？外部专用存储如何获取，支持什么镜像文件格式、大小限制是多少？10 月 20 日 23:59 截止是否为北京时间？

## 3. 官方回复后，按回复下载资料

1. 让官方给出可保存的文字、公告链接或原始附件；优先拿 **ID 修正说明、B2 镜像取得方式、正式资源/时限说明**。一次只回复部分也先保存、交回来。
2. 需要重新下载工程包时，打开[官方 B2 数据分享](https://yun.139.com/shareweb/#/w/i/2xG3smej8W29n)。若弹出中国移动云盘登录，由你按页面提示登录；这个登录与咪咕算力平台登录分别处理。
3. 分享页中找到 **“数字人综合情感陪伴对话模型”**，按页面提示选择整个项目目录，点击顶部 **“下载”**。当前可见内容为 participant、训练-验证-数据集、README.md、test_inference_data.jsonl、咪咕仝学平台实例创建demo V1.docx；保留完整目录结构。若下载按钮要求先选文件，按提示选齐目录内容；不要只下载 README。
4. 建议保存到你自己新建的 `D:\Ddownload\B0官方补充\2026-10-10\`，保留旧 ZIP；新文件原样保存，记录来源链接和下载日期。无需手动改脚本、ID、配置或输出规则，也无需手算摘要，我收到后计算和比较。
5. 如果给的是镜像 `.tar` 或 `.tar.gz`，按官方链接下载并保留原文件；如果只给镜像地址/版本文字，直接复制给我，由我处理。镜像文件的 SHA256 与 registry digest 是不同标识，不需要你判断。

## 4. 如果官方让你“去平台看镜像”

1. 打开[咪咕仝学控制台的镜像列表](https://aigpu.migu.cn/train/control/mirror/list)。登录后左侧 **“训推服务 → 模型镜像”**，选择 **“公有镜像”**。
2. 点击 **“vLLM”**，确认版本行的框架为 **“vLLM（大赛专用镜像-对话模型）”**，版本为 `0.19.0-ubuntu22.04-p3.12-cuda12.8`；把页面截图和客服确认文字交给我。
3. 该详情页目前只显示版本、状态、28.29 GB 等信息和 **“立即部署”**，没有显示镜像地址/digest。为收集资料先停在此处；不要点击“创建并开机”去查摘要。若官方确实要求进入实例才能取得环境资料，先把这个要求交给我，再安排有预算的操作。
4. 如果官方明确只支持平台路线、不提供外部镜像，保存这条答复；我按确认后的路线修订 B0。没有公开 digest 时，不能用页面版本名称代替摘要，也不需要你自己设法生成一个。
