# AI队：评审资料索引

本镜像的基础模型为 `b2-a-qwen2.5-0.5b-instruct-base-v1`。本目录包含技术方案、实验设计/报告、既有训练日志和平台调优观察，供专家评审使用；推理入口与本目录分开，不读取评审资料或答案作为测试上下文。

- `B/B7-技术方案.md`：模型、情感字段回退、记忆隔离与禁网部署。
- `B/B7-实验设计与报告.md`：区分A实验、B真实镜像、正式平台成绩；本文件冻结时B7实测尚未进行。
- `B/B7-A交接核对.md`：纠正A12中旧状态、数据来源和GPU计费口径，记录平台设备EPERM现象；不确定平台根因。
- `B/B7-平台GPU尝试记录.md`：固定A平台原始记录的逐行摘录，保留UTC时间和实际故障输出；去掉连接地址与实例私有标识，不冒称本轮B重跑。
- `A/reports/model/` 与 `A/training/logs/`：A固定公开提交的来源、CPU短训练、原始逐步日志和小样本比较。
- `A/data/training/processed_official/official_samples_report.json`：后续真实官方数据子集整理，未当作已完成训练。
- `B/evidence/`：B6真实GPU禁网流程、样本诊断及实际依赖快照；这些是父镜像记录，不代替新镜像B7验收。
- `REVIEW-MANIFEST.json`：本目录每个文件的SHA256、字节数和固定来源；最终新image ID、导出SHA和B7运行结果在镜像外记录，避免自身摘要循环。

A材料原文保留其历史日期与链接。原文中的相对源码/完整数据链接指向原仓库，未将所有训练数据或脚本放入本评审目录；可按清单固定提交在项目公开仓库查看。它们不影响离线推理。A4中的official50是合成样本的输出格式名，A5的CPU速度不能代表本提交基线的正式GPU性能，A5当时未跑团队入口不意味着后来的B6失败。

本提交不含尚未收到的sft-short权重，不声称GPU训练完成、临床效果、正式测评分、晋级或商业客户。完整模型/tokenizer/许可与原配置在 `/root/participant/weights`，实际入口为 `bash /root/participant/start.sh TEST_FILE RESULT_DIR`。
