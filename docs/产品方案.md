# “伴学”综合情感陪伴数字人产品方案

> **项目选题**：综合情感陪伴对话模型（数字人）
> **项目代号**：B2 伴学 (Companion Student)
> **责任分工**：分工 C（产品交付负责人）
> **基线日期**：2026-10-10

---

## 1. 目标用户与核心痛点

### 1.1 目标用户画像
“伴学”聚焦于高校在读专科/本科/研究生群体，特别是处于期末备考、升学考研、跨专业考公或毕业求职关键节点的高校青年。

### 1.2 核心痛点分析
1. **备考焦虑与阶段性倾诉无门**：高数、考研、等级考试临近时，学生常伴有较强焦虑感，向父母倾诉易引发过度担忧，向同窗倾诉易带来心理负担。
2. **人际摩擦与隐私顾虑**：宿舍作息、性格差异等导致的小摩擦频发，学生渴望情绪树洞，但极度注重隐私，担心线上 SaaS 云端模型记录泄露个人人际敏感信息。
3. **传统聊天工具缺乏记忆与共情**：通用聊天机器人“聊过即忘”，无法记住用户的考试科目、习惯称呼或目标，且多以生硬大道理堆砌，缺乏温和的情感承接与表情共振。

### 1.3 产品定位与伦理边界
- **日常情感支持**：“伴学”定位于**大学生的全天候日常情绪树洞与温和伴学助手**，提供积极倾听、温和鼓励与基于事实记忆的情绪承接。
- **免责与伦理边界**：
  - 本产品**严格不提供任何心理疾病诊断、精神医疗建议或疗效承诺**；
  - 情绪与表情输出仅作为多模态交互辅助（界面严格标注“情绪估计”），绝不作为医学心理评估；
  - 界面设置醒目的心理求助指引，若遇严重心理危机，引导其直接拨打全国心理援助热线（如 12356）或联系所在高校心理健康中心。

## 2. 核心功能与交互体验

### 2.1 轻量多模态数字人表情联动
- 提供四种直观、温暖的自研矢量表情状态：
  - **平静注视 (`neutral`)**：初始状态或常规信息询问；
  - **微笑陪伴 (`smile`)**：用户表达开心、分享成就或备考通过时展现；
  - **关切倾听 (`concern`)**：用户倾诉焦虑、难过、疲惫时触发；
  - **专注倾听 (`listening`)**：用户倾诉矛盾、进行长篇吐槽或反思时展现。
- **100% 离线自包含**：全部表情资产均以本地 SVG 内嵌呈现，不依赖在线图床或 CDN，满足断网离线评测与隐私合规要求。

### 2.2 事实型长期记忆沉淀与纠正（Fact-based Long-term Memory）
- **严格遵循用户主动确认原则**：不擅自将大模型推测的情绪状态、画像标签存入数据库，仅持久化用户显式确认的核心事实；
- **标准化事实白名单**：
  - `preferred_name`（称呼，如“小航”、“陈同学”）
  - `study_goal`（学习目标，如“英语六级 550 分”、“考研上岸”）
  - `exam_subject`（关注的考试科目，如“高等数学”、“线性代数”）
  - `response_preference`（回应偏好，如“温柔鼓励”、“简明要点”）
  - `hobby`（兴趣爱好，如“摄影与短视频”、“篮球”）
- **用户完全掌控权**：
  - 支持原地修改纠正（如“高数”变更为“线代”，新值覆盖旧值并更新时间戳）；
  - 支持记忆一键启闭与一键清空；关闭状态下保留已有事实但不检索、不持久化新项；
  - 删除单个对话会话不影响用户级长期记忆。

### 2.3 健壮的非流式交互与防重重试
- 客户端在首次提交时生成唯一的 `client_turn_id`，生成过程中前端输入框锁定；
- 若出现网络超时或模型计算排队（409/503），客户端保留当前输入与未完成轮次，支持原 `client_turn_id` 重试，后端根据 `(session_id, client_turn_id)` 实现天然幂等，避免重复扣费或重复落库。

## 4. 模型训练与评测实测结论（引用角色 A 真实报告）

根据角色 A 在 `reports/model/A7-最终报告.md` 与 `reports/model/A5-评测结果.md` 中的实测数据：

1. **模型基座与许可**：
   - 基座模型：Qwen 官方公开基线 `Qwen2.5-0.5B-Instruct`（参数量 494M，Apache-2.0 协议）；
   - 依赖本地化：8 个权重文件完整落盘，离线 SHA-256 校验；断网加载可用。
2. **训练尝试记录**：
   - 样本集：200 条高质量样本（150 条共情多轮对话 + 50 条官方格式标注）；
   - 微调架构：冻结前序层，训练最后 4 层注意力与归一化层（可训练参数 59.6M，占比 12.07%）；
   - 训练算力消耗：由于评测机无 GPU 显卡（`torch.cuda.is_available() == False`），训练使用 CPU 运行 7.33 分钟完成，**GPU 卡时真实消耗为 0**（平台赠送的 20 卡时券保留未消耗）；
   - 训练收敛：Loss 由 3.6161 降至 2.4668，验证 Loss 2.2982。
3. **基线与候选模型对比（12 案例评测）**：
   - **平均回复长度**：基线 66.1 字 → 候选微调 29.2 字（更克制、不堆砌空话）；
   - **平均推理耗时**：基线 2527 ms/轮 → 候选微调 **1239 ms/轮**（提速约 51%）；
   - **复读退化轮次**：0 / 36 轮（完全无退化复读）；
   - **官方 JSON 遵循率**：基线 0/3 → 候选 1/3（小模型直接输出严苛嵌套 JSON 仍有难度，系统配备了规则兜底保障 100% 格式合法）。

## 5. 扩展应用可行性分析（养老与智能客服）

虽然当前主场景聚焦于“大学生日常陪伴”，但本方案的技术构架（轻量级离线模型 + 事实型长期记忆 + 情绪多模态表情联动）具备向其他垂直领域的横向拓展能力：

### 5.1 适老情感陪伴场景（扩展应用）
- **适用性**：独居老人对服药日程、子女称谓、慢性病偏好有较强记忆需求；
- **改造点**：
  - 将记忆白名单扩展为 `medication_schedule`（用药时间）、`chronic_condition`（慢病注意点）、`family_relation`（亲属称呼）；
  - 接入语音合成（TTS）与语音识别（ASR），降低老年人打字门槛；
  - 保持全本地断网部署，消除老人健康与作息隐私泄露风险。

### 5.2 校园/企业客户服务（扩展应用）
- **适用性**：辅导员助手、招生问答、办事指南等轻量咨询；
- **改造点**：
  - 挂载校园 FAQ 知识库与教务政策检索；
  - 遇到学生严重情绪波动或敏感词时，自动触发转接辅导员或人工坐席机制。

## 6. 社会价值、潜在风险与应对措施

### 6.1 社会价值
1. **填补青年心理支持真空**：为高校学生在夜间及备考关键期提供低心理门槛、零评判压力的即时倾诉渠道，平缓日常情绪波动；
2. **高保真隐私保护**：采用本地轻量化模型与端侧记忆存储，不将聊天数据上传商业公有云，筑牢校园心理数据防线；
3. **绿色低碳能耗**：基于 0.5B 超轻量模型，可在消费级 CPU 或单张入门显卡上平稳离线运行，边际推理成本极低。

### 6.2 潜在风险与应对预案
| 风险项 | 风险表现 | 应对与缓解策略 |
|---|---|---|
| **情感过度依赖** | 学生将数字人视为唯一精神支柱，脱离现实人际 | 引导用户设立现实社交与自护目标；提示“伴学是你的树洞，也期待你与朋友共同散步”。 |
| **模型偶发幻觉与误答** | 针对专业课知识点产生编造回复 | 提示词明确“伴学关注情感承接而非题目答疑”；若涉及具体考题，引导查阅教材或请教老师。 |
| **提示注入与记忆污染** | 恶意输入尝试越权覆写系统设定 | 严格限定事实 Key 白名单，对 Value 实施去首尾空白与 200 字硬限制；记忆采用明确的只读 JSON 上下文注入。 |
| **极端危机干预** | 出现自残、抑郁极端倾向输入 | 系统敏感词拦截；界面强提示心理求助热线与校心理中心，不以机器模型代替危机干预。 |
