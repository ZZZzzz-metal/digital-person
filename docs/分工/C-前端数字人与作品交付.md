### C2. 聊天页面与四种数字人表情（10/09 当天）

**输入：** client/mock、Expression 枚举。

**输出：** 一个可用页面：会话列表、聊天记录、输入区、发送/重试、数字人和状态栏；窄屏可用即可。数字人使用自己绘制的本地简易 SVG 或有明确许可的本地素材，表情仅 `neutral`、`smile`、`concern`、`listening`。无 CDN、在线字体或远程图片依赖，不做视觉精修。

发送采用非流式：首次点击生成 `client_turn_id`，同次失败重试沿用该 id；等待时禁用重复发送。输入为空或超过 2,000 字符不发送。用户气泡可临时显示“发送中/失败”，成功后才按服务器记录呈现为已完成，不把失败轮次冒充已保存记录。切换会话时不要把旧请求结果贴进新会话。

表情以响应的 expression 为准；未知值用 neutral。`emotion` 若展示，写“情绪估计”；`retrieved_memories` 的区块叫“本轮参考记忆”，不能声称每项已被模型使用。显示 model_version 与 mock 标识，耗时只取实际 elapsed_ms。

**完成检查：** 四种表情可演示；连续 6 轮记录顺序正常；重复点击不会发两次；失败可重试；空会话、等待和超长输入有反馈。当天把可独立运行的前端交给 B。

### C3. 真 API 与记忆操作（10/10–10/11）

**输入：** B 的 schema、可运行 API；A/B 的真实 engine 就绪状态。

**输出：** 核对后的类型、真实模式、记忆卡片和必要错误反馈。首次访问由 B 分配 cookie；我不做登录系统，不伪造用户身份。提供明确的保存为记忆、修改、删除、关闭、清空按钮；用户主动点击确认才持久化。

只保存称呼、学习目标、偏好等主动确认的事实，不自动存储模型情绪判断。关闭记忆后显示“已关闭，已有记忆保留”；关闭不等于清空。删除会话时说明长期记忆保留；清空记忆另行确认。GET 返回的 enabled/items 是唯一状态来源，接口失败不先宣布成功。

错误分别处理：400 显示参数提示；404 提示资源不可访问；409 提示当前会话正在生成；503 显示模型暂不可用与重试。`GET /health` 返回 200 但 degraded 时仍显示实际状态，不当作模型成功运行。真实响应 `is_mock=true` 时继续显示“演示数据”。

**完成检查：** 真模型聊天→保存高数→新会话引用→确认改为线代→再次引用；记忆关闭后不读写；两个独立浏览器/cookie 不串记忆；模型关掉后真实出现 503，无固定话术兜底。依赖未到时保留复现说明并先做 C4/C5。

### C5. 产品方案与假设商业测算（10/12–10/14）

**输入：** 截图中的课程要求、A/B 已交付的真实技术结论。

**输出：** `docs/产品方案.md`、`docs/商业测算.md` 初稿。产品主场景只做大学生日常情绪陪伴，围绕学习压力、宿舍相处、生活倾诉写用户、痛点、功能、交互和社会价值；养老/客服只写扩展条件。技术图或文字完整串起页面→后端→短期历史/长期记忆→本地模型→回复/表情，并区分演示服务与官方自动测评入口。

商业模式选一项主方案，例如假设的校园机构服务；C 端订阅作为对照。没有调研就写“待验证”，不用虚构客户、访谈、市场份额或疗效。测算统一声明“未验证假设”，给低/中/高三个场景和可替换参数：

- 月付费人数 = 月活用户数 × 付费比例；月收入 = 月付费人数 × 假设月单价。
- 月请求量 = 月活用户数 × 人均日请求 × 30；GPU 卡时 = 月请求量 × 实测单次 GPU 秒数 ÷ 3,600。没有实测耗时时保留变量，不写成测得成本。
- 月推理成本 = GPU 卡时 × 假设卡时单价；简化月毛利 = 月收入 − 推理 − 存储 − 运维；另列一次性开发投入与固定开支，不称为净利润。

敏感性至少覆盖付费比例、请求量和算力单价，计算结果可复核。风险写隐私与授权、模型误答、对记忆的误用、依赖和资源限制及具体应对；产品定位为日常支持，不给诊断、治疗、法律结论或效果承诺。

**完成检查：** 对照课程五类评分内容均有对应段落；训练/评测数字能指向 A 的记录；商业数字都能找到假设与公式；无依据的结论改为待验证。
