## 2. 最终验收清单逐项核查（Checklist）

对照 `docs/分工/C-前端数字人与作品交付.md` §最终验收清单：

- [x] **mock 可独立启动且明显显示“演示数据”；真实模式不偷偷回退**：
  - `apps/web/src/api/mock.ts` 返回响应均含 `is_mock: true`；
  - 界面顶部、数字人头像浮动标签及气泡底部均醒目展示“演示数据”；
  - `apps/web/src/api/client.ts` 在真实模式遇到网络失败或 5xx 时直接抛出 `ApiError`，由界面提示 `[MODEL_UNAVAILABLE]`，绝不降级为假回复。
- [x] **固定 API/DTO 与 B 的 schema 一致；cookie 用户隔离可联调**：
  - `src/api/types.ts` 与 `src/b2_core/contracts.py` 字段 100% 对应；
  - `client.ts` 携带 `credentials: 'include'`，保持后端的 `b2_anon` cookie 隔离。
- [x] **四种本地表情、发送等待、失败重试、空状态可用**：
  - 数字人配备 `neutral`、`smile`、`concern`、`listening` 四种本地矢量图；
  - 发送时按钮锁定为“生成中...”，输入框禁用；
  - 空输入或空白字符不可点击发送，支持最多 2000 字符计数展示。
- [x] **同次重试保持 client_turn_id；失败不产生虚构助手消息**：
  - 点击重试时，调用 `handleRetryPending`，严格复用失败轮次的 `clientTurnId`；
  - 失败轮次仅在用户气泡标记“发送失败”，不生成 assistant 虚假气泡。
- [x] **记忆保存/调用/确认纠正/关闭/清空能操作，参考记忆命名准确**：
  - 严格支持 5 个白名单 key（称呼、学习目标、考试科目、回应偏好、兴趣爱好）；
  - 用户显式点击“确认保存”后持久化；同 key 原地更新覆盖；
  - 关闭记忆后保留数据但不检索；支持二次确认清空；
  - 气泡中检索出的候选明确标注为“本轮参考记忆”。
- [x] **真模型 503 有真实错误反馈；断网演示不依赖在线模型或素材**：
  - 503 时界面展示 `[MODEL_UNAVAILABLE] 模型暂不可用` 真实错误；
  - 前端零 CDN、零外网字体、零在线 API，断网完全可用。
- [x] **三个剧本格式一致，未执行的检查明确标注**：
  - `exam-memory.json`、`roommate-switch.json`、`positive-chat.json` 格式一致（`id`、`title`、`memory_setup`、`turns`）；
  - 校验通过，各轮次均包含 `text` 与 `check`。
- [x] **方案与测算有依据或假设标签，训练效果不虚构**：
  - 方案与测算中所有数据均标注“未验证假设”；
  - 模型数据真实引用角色 A 在 CPU 上实测的 1239ms 耗时与 0 卡时消耗，不虚构未实测的指标。
