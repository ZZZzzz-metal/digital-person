## 1. 演示环境准备与前置确认（录制前 Checklist）

在录屏开始前，请录制人员确保：
1. **服务启动状态**：

## 2. 逐秒分镜脚本与口播旁白表（总计 2分40秒）

### 镜头一：场景引入与产品定位 (0:00 - 0:20，共 20 秒)
- **时间轴**：`00:00 - 00:20`
- **画面分镜**：
  - 屏幕居中展示“伴学”交互主界面全景：左侧会话栏、中部对话流、右侧自研数字人头像（初始为平静注视 `neutral`）与长期记忆面板；
  - 鼠标移向顶部 Header，突出展示“伴学 · 综合情感陪伴数字人”标识与服务健康状态。
- **页面操作**：鼠标轻微滑动，聚焦于数字人和顶栏。
- **旁白口播（建议语速约 220 字/分）**：
  > “各位评委老师好！高校青年在期末备考、升学深造与宿舍人际中，常面临高频的情绪起伏，却往往因为怕添负担或隐私顾虑而倾诉无门。为此，我们团队打造了‘伴学’——一款面向大学生的轻量级情感陪伴数字人。它具备三大核心能力：多轮共情理解、自主事实记忆、以及 100% 离线自包含的高速轻量推理。”
- **屏幕字幕**：`场景：高校青年日常备考与人际倾诉 | 纯本地离线端侧模型`
- **检查点**：展示自研矢量头像；无外部网络连接请求。

### 镜头二：日常倾诉、共情理解与表情联动 (0:20 - 0:55，共 35 秒)
- **时间轴**：`00:20 - 00:55`
- **画面分镜**：
  - 演示者在输入框输入剧本第一轮：“我这几天一想到考试就特别紧张焦虑，书也看不进去。”
  - 点击发送，输入框出现“发送中...”，随后气泡呈现已完成状态；
  - 数字人头像动态由 `neutral` 切换为关切倾听表情 `concern`，右侧元数据实时更新；
  - 随后输入第二轮：“尤其是高数，上周模拟考没及格，好怕这次挂科。”
  - 助手温和回应，表情维持关切专注，界面情绪估计标签高亮显示为“焦虑”，耗时显示约为 1200ms。
- **页面操作**：
  1. 键入文字并回车；
  2. 观察非流式返回时的平稳交互与气泡生成；
  3. 鼠标悬停在数字人“关切倾听”标签与“情绪估计: 焦虑”标签上。
- **旁白口播**：
  > “现在，我们向伴学倾诉真实的备考焦虑。可以看到，点击发送后，系统通过离线 Qwen 0.5B 本地模型进行共情推理，平均响应耗时仅 1.2 秒左右。伴学不仅没有堆砌冰冷的大道理，而是准确识别出用户的焦虑情绪，并自适应将数字人状态切换为‘关切倾听’表情，给学生以温暖、及时的心理托底。”
- **屏幕字幕**：`情绪估计：焦虑 | 表情自适应切换：关切倾听 (concern) | 平均响应：~1.2s`
- **检查点**：助手回复承接担忧；表情正确切换；界面展示“情绪估计”，不出现医疗诊断字样。

### 镜头三：长期事实记忆沉淀、跨会话调用与主动纠正 (0:55 - 1:40，共 45 秒)
- **时间轴**：`00:55 - 01:40`
- **画面分镜**：
  - 聚焦右侧“长期事实记忆”面板。演示者选择事实类型 `exam_subject`（关注考试科目），输入 `高等数学`，点击“确认保存/纠正记忆”；
  - 记忆卡片实时新增并展示保存时间戳（北京时间）；
  - 点击左侧“+ 新建会话”，开启一个全新的干净对话窗口；
  - 演示者在新会话中提问：“今天想聊聊昨天提到的那门考试。”
  - 助手在新会话的回复中自然结合上下文：“记得你之前提到正在复习高等数学，今天感觉复习进度怎么样？”并在消息底部展开“本轮参考记忆：关注考试科目: 高等数学”；
  - 演示者继续测试纠正能力，输入：“之前说错了，其实是线性代数。”
  - 演示者在右侧面板一键将记忆更新为“线性代数”；
  - 演示者再次追问：“现在你记得我担心哪门考试吗？”，助手准确回应“线性代数”，不再出现已被覆盖的高数事实；
  - 展示“记忆关闭”开关：关闭后卡片保留，但不参与后续会话检索。
- **页面操作**：
  1. 在面板保存 `exam_subject = 高等数学`；
  2. 点击新建会话，发送关联问题；
  3. 点击修改为 `线性代数` 并再次提问验证；
  4. 演示切换记忆开关。
- **旁白口播**：
  > “通用聊天机器人常常‘聊完就忘’，而伴学设计了严格受用户掌控的‘事实型长期记忆引擎’。我们坚持‘用户主动确认原则’，不随意将模糊的情绪推测落库。我们把关注科目保存为‘高等数学’后，即便切换到全新的独立会话，伴学依然能准确命中并引用该事实。如果用户说‘记错了，是线性代数’，用户点击修改后即可原子化覆写，旧记忆彻底失效。同时，用户可随时一键关闭或清空记忆，彻底保障隐私自主权。”
- **屏幕字幕**：`跨会话事实记忆检索 | 用户主动确认机制 | 原地纠正覆盖旧值 | 独立用户隔离`
- **检查点**：新建会话能调出记忆；修改后立即生效；关闭记忆不报错。

## 3. 队员录屏实操步骤说明（人工录制待办清单）

由于 Agent 运行环境无法捕获桌面声卡与视频流，请队长或指定队员按照以下 6 步完成实际视频录制并归档：

1. **软件准备**：安装 OBS Studio、剪映或系统自带录屏软件（Win + Alt + R）；
2. **分辨率设置**：录制窗口固定为 1920×1080，帧率 30fps 或 60fps；
3. **音频录制**：按本文第 2 节口播旁白进行配音录制（可使用系统麦克风或剪映文本朗读功能合成）；
4. **画面对齐**：按照镜头一至镜头五的时间节点完成点击、输入和界面切换；
5. **合规检查**：
   - 检查视频中是否包含任何个人真实隐私信息（如有，替换为虚构代称如“小航”、“陈同学”）；
   - 检查视频时长是否严格落在 **2 分 15 秒 至 2 分 45 秒** 区间；
   - 确认无任何在线商业 API 调用痕迹；
6. **文件归档**：
   - 将录制完成的视频命名为 `demo_video_2min40s.mp4`，放置于 `submission/` 或网盘指定交付目录，并在 `docs/交付清单.md` 中更新其最终哈希与文件状态。
